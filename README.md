# ApexPlanet Internship — Task 5

## Web Application Penetration Testing Using DVWA

### Project Overview
This project demonstrates web application penetration testing using Damn Vulnerable Web Application (DVWA) in a controlled local lab environment.

### Objectives
- Understand common web application vulnerabilities.
- Explore SQL Injection using DVWA.
- Observe and document test results.
- Learn security controls and vulnerability prevention.

### Tools Used
- Kali Linux
- DVWA
- Burp Suite
- SQLmap

### Practical Work
1. Set up DVWA in a local lab.
2. Configure the DVWA security level.
3. Test normal input on the SQL Injection page.
4. Document observations and screenshots.
5. Explain secure coding practices, including parameterized SQL queries.

### Security Recommendations
- Use prepared statements and parameterized queries.
- Validate user input on the server.
- Apply least-privilege database permissions.
- Retest after implementing security fixes.

### Scope
All testing is performed only in an authorized, local lab environment.

### Disclaimer
This project is intended for cybersecurity education and authorized security testing.
